# Scientific review queue

These questions intentionally block automatic mapping until NASA evidence resolves them.

- [ ] Does NASA document a calibration from Fan display to physical airflow?
- [ ] What physical quantity, if any, does Air display represent?
- [ ] How should Flow restrictor values be represented beyond raw instrument metadata?
- [ ] Which BASS-II material strings can be parsed deterministically without losing qualifiers?
- [ ] Are all initial CO and CO2 readings experimental conditions, or should any remain contextual measurements?
- [ ] Which outcome labels are scientifically comparable within BASS-II?
- [ ] Which fields change meaning when the schema is applied to FLEX?
